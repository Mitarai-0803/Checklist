# Checklist

> シンプルなチェックリスト管理ツール

チェックリストは、タスクを一覧で管理するだけのシンプルなタスク管理用ツールです。
これは自分用機能ですが、プログラムのファクタリングメモ用にファイルを一括でUploadして、ファイル名でチェックリストに追加することもできます。

※まだ一括で削除のボタンと並べ替え機能ができていないので追加予定です。

https://mitarai-0803.github.io/Checklist/

## 特徴

- シンプルな操作感
- どのファイルのリファクタリングをしたかなどのメモ用にファイル名でリストに一括追加

## 使用技術

- HTML
- CSS
- JavaScript
